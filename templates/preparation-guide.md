# 从资料到可聊天的角色

1. 原始聊天记录单独保留，在副本中移除个人识别信息、第三方隐私和不宜上传的私密内容。
2. 填写 `character-profile.md`。将明确事实、可观察的表达习惯和个人解读分开。
3. 用 `dialogue-samples.md` 整理连续对话。覆盖闲聊、关心、玩笑、兴趣、忙碌和分歧；每段保留约 5—15 条消息，标注关系阶段。
4. 用 `shared-memories.md` 整理事件。时间不确定就注明，缺失细节不要补写成事实。
5. 用 `image-notes.md` 写场景说明；本版不直接读取图片。头像仅用于本地视觉展示。
6. 将整理内容复制到网页对应字段，保存，或参照 `data/character.example.json` 制作角色 JSON 并导入。
7. 留出 10 段未提供给模型的对话作对比：观察措辞、回应长度、情境变化，以及是否编造记忆或心理。

第一版目标：一页人物设定、30 段对话样本、10 条记忆、一页角色规则。不要一开始就倾倒全部聊天记录。

这些 Markdown 是人工整理模板，服务不会自动读取它们；网页保存的数据才是运行时使用的资料。
